# BankAccount 클래스

*클래스 생성*

1. 은행계좌번호, 잔액을 담기 위한 프로퍼티들을 선언
2. 현재의 잔액을 표시하기 위한 메서드 선언
3. 새로운 클래스의 인스턴스를 생성할 때에 초기화/소멸 작업  >>> 이해 ㄴㄴ


*인스턴스 생성*

var account1: BankAccount = BankAccount()   // 타입 지정

*점 표기법을 이용한 클래스 접근*

클래스인스턴스.프로퍼티명
클래스인스턴스.인스턴스메서드()


*저장 프로퍼티와 연산 프로퍼티*

저장 프로퍼티: 상수, 변수 값
연산 프로퍼티: 가져오는 시점에서 로직처리된 값 - getter: 반환
                                   ㄴ setter: 연산 코드 포함

BankAccount 클래스에 은행 수수료를 제외한 현재 잔액을 담는 프로퍼티가 추가로 필요하다면
-> 값에 대한 요청이 있을 때마다 계산되는 연산 프로퍼티를 이용하는 것이 효율적임
